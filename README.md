# ACADEMY – Sistema de Gestão Acadêmica

## Sobre o projeto


O ACADEMY é um sistema de gestão acadêmica desenvolvido para centralizar e organizar informações relacionadas a alunos, professores, administradores, cursos, turmas e atividades educacionais.

O sistema integra a linguagem C com um banco de dados relacional MySQL, disponibilizando uma interface de terminal e uma interface gráfica desenvolvida com GTK.

## Funcionalidades

- Autenticação administrativa.
- Cadastro e gerenciamento de usuários.
- Gerenciamento de alunos e professores.
- Cadastro e gerenciamento de cursos e turmas.
- Gerenciamento de matrículas.
- Gerenciamento de materiais didáticos e atividades.
- Registro e consulta de notas.
- Cálculo de médias acadêmicas.
- Consultas e relatórios estatísticos.
- Arquivamento de turmas.
- Interface gráfica para gerenciamento de informações acadêmicas.

## Segurança e melhorias

- Proteção de senhas utilizando PBKDF2-SHA256 com salt.
- Configuração das credenciais do banco de dados por variáveis de ambiente.
- Proteção dos dados textuais utilizados em consultas SQL.
- Validação de dados de entrada.
- Tratamento de erros.
- Restrições de integridade no banco de dados.
- Testes automatizados de funções de segurança.
- Automatização da compilação.
